# 市场简报上下文测试记录

## 测试目的

使用用户提供的《每日市场简报_2026-10-08.pdf》整理出一份可追踪的市场上下文夹具，测试 Core Agent 是否能够接收外部市场信息、标记异常和冲突，并把证据交给 Risk，同时保持原有 Quant 计算、Memory 规则和 Risk 边界不变。

这不是实时行情接入，也不是对 PDF 内容的投资判断。PDF 中的数值仅用于本地可重复测试，原始 PDF 不上传 GitHub。

## 处理方式

Core Agent 只把市场简报作为 `market_context` 传递给主链路：

```text
市场简报 → 格式和来源校验 → 异常与冲突标记
         → 作为 Artifact 和 ToolResult 留痕
         → 通过 Risk Handoff 交给 Risk 复核
```

市场上下文不会改变已有的组合健康指标、候选方案、回测或模拟结果。Core Agent 没有复制 Quant 的计算逻辑，也没有修改 Memory 的 consent、范围、生命周期和清理规则。

## 测试结果

### 1. 市场简报格式校验

结果：通过。

- 市场资产记录数量、字段、数据日期和来源状态校验通过。
- 重复 `asset_id` 会在 Core Agent 输入边界被拒绝。
- 市场数据不是正数、涨跌幅不是数字或来源状态不在允许范围时会被拒绝。

### 2. 异常波动标记

结果：通过。

当前演示阈值为单日绝对涨跌幅不低于 3%。系统标记出：

- 创业板指：-3.15%
- NYMEX 原油：+4.15%

系统只标记“异常波动”，不把异常波动直接转换成买入或卖出动作。

### 3. 价格和新闻冲突

结果：通过。

原油价格上涨与地缘消息缓和被记录为：

- signal_id：`oil-message-conflict`
- status：`REVIEW_REQUIRED`

系统保留两边证据，不强行选择“相信消息”或“相信价格”，也不自动生成交易动作。

### 4. Quant 不被重新计算

结果：通过。

同一份投资组合分别进行“无市场上下文”和“带市场上下文”运行后：

- 健康报告中的收益、波动、最大回撤和 Sharpe 等指标一致。
- A、B、C 候选方案的目标权重一致。
- 情景模拟的比较结果一致。
- 新增的只是市场上下文 Artifact、ToolResult 和 Risk 证据引用。

运行时示例：

- `contract_version`：`investment-agent.v1`
- `request_id`：`req-market-brief-runtime-001`
- `risk_handoff.status`：`PENDING_REVIEW`
- `execution_allowed`：`false`
- `abnormal_moves`：创业板指、NYMEX 原油
- `unresolved_conflicts`：`oil-message-conflict`

### 5. Risk 边界

结果：通过。

市场上下文被放入 `artifacts.market_context`，并通过 `risk_handoff.evidence.market_context_id` 提供给 Risk。主流程仍然停在 `HANDOFF_REQUIRED`，没有因为市场数据而绕过 Risk，也没有把前端确认当成交易授权。

### 6. Memory 边界

结果：通过。

本轮只新增市场上下文校验和测试夹具，没有调用、修改或放宽 Memory 的 consent 规则、会话范围、生命周期和清理机制。

## 结论和限制

本轮证明 Core Agent 可以在不改动 Quant、Memory 和 Risk 规则的前提下接收一份有数据日期和来源状态的市场简报，把异常与冲突变成可追踪的上下文，并交给 Risk 复核。

当前仍是本地演示：市场简报是固定测试夹具，不是实时数据源；没有独立的 Risk Consumer；没有把新闻归因、宏观变量或商品价格直接接入组合收益预测。后续如要接入真实数据，必须先和 Quant、Research、Risk 共同确定版本化字段、来源可信度、时间窗口和回写方式。
