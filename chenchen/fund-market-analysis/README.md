# Fund Market Analysis

## 项目定位

这是 Personal AI Fund Manager 的独立实验项目，专门研究“当前基金市场处于什么状态、有哪些可验证的风险信号、哪些地方需要继续观察”。

它暂时不接入当前投资产品，不修改 Core Agent、Quant、Memory、Risk 或 UI。后续只能通过版本化的市场上下文输出与主项目融合。

## 第一阶段问题

- 当前市场是偏风险、偏防守，还是信号混合。
- 股票、利率、商品和基金分类之间是否出现同向或冲突信号。
- 基金类别的表现和资金变化是否有足够数据支持。
- 哪些结论有来源，哪些只能标记为待确认。
- 当价格和新闻方向冲突时，如何输出多候选解释和置信度，而不是强行归因。

## 第一阶段功能草案

1. 市场状态卡：风险偏好、利率环境、市场广度和数据新鲜度。
2. 基金分类比较：权益、债券、商品、混合等类别的区间表现、波动和回撤。
3. 异常波动检测：对单日涨跌幅、利率变化和类别内部背离做标记。
4. 证据链：每个信号记录数据日期、来源、计算口径和限制。
5. 冲突信号处理：价格、新闻和利率方向不一致时输出 `REVIEW_REQUIRED`。
6. 观察清单：把需要 T+1 或下一次数据更新确认的信号留下来。

## 明确不做

- 不输出“现在应该买哪只基金”的直接结论。
- 不把短期市场状态当成收益预测。
- 不把外部新闻直接改写成 Quant 组合收益或回撤结果。
- 不绕过 Risk 生成交易授权。
- 不把未经核验的数据写成确定事实。

## 测试数据

`data/sample-market-context.json` 是一份基于 2026-10-08 市场简报整理出的固定示例，只用于验证数据结构和冲突处理。它不是实时行情，也不代表当前市场判断。

## 后续与主项目的融合边界

本项目未来只输出类似下面的上下文：

```json
{
  "contract_version": "fund-market-analysis.v0",
  "as_of": "2026-10-08",
  "regime": "MIXED_REVIEW",
  "signals": [],
  "evidence": [],
  "limitations": []
}
```

Core Agent 只消费已经带有数据日期、来源和限制的结果；是否影响具体组合，仍由 Quant 和 Risk 按各自职责处理。
